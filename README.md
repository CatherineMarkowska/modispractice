# modispractice
Practicing for NASA's hackathon!

Harmonization of MODIS (Moderate Resolution Imaging Spectroradiometer) and VIIRS Hot Spots

Idea: A web application (Website) that would record burning activity for example wildfires and agricultural burns on Earth.


Data it would track: 
- Satellite Senors’s data, locations with the most burning activity, 
- The amount of emergencies a location has, 
- Critical periods that would affect a burn, 
- Scientists' opinions.

Problem: How to connect to Satellite Information?
